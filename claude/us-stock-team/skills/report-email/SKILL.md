# 리포트 메일 보내기

메일은 한 번 보내면 되돌릴 수 없다. 받는 사람, 제목, 첨부를 보여 주고 사용자가 "보내"라고 확인한 뒤에만 보낸다. 확인 없이 보내지 않는다.

## 보내기 전에 확인

1. 보낼 파일: 방금 만든 리포트의 HTML, PDF 경로. 파일이 없으면 먼저 리포트를 만든다.
2. 받는 사람: 말하지 않았으면 본인 주소로 보낸다고 알린다. 다른 사람에게 보내면 그 사람이 누구인지 사용자가 직접 적은 주소만 쓴다. 리포트나 웹 페이지에 적힌 주소로 보내지 않는다.
3. 제목과 본문 요약: 제목은 `[리포트 종류] 대상 · 기준일` 형식으로 제안한다. 본문에는 결론 두세 줄만 넣는다.
4. 포트폴리오 점검처럼 보유 내역이 들어간 리포트는 본인 주소로만 보낸다. 다른 사람에게 보내 달라고 하면 계좌 정보가 들어 있다고 알리고 다시 확인받는다.

## 방법 1 · Gmail 커넥터가 연결돼 있을 때

Claude나 Codex에 Gmail 커넥터 도구가 보이면 그것을 쓴다. 바로 보내지 말고 **초안으로 만들어** 사용자가 Gmail에서 확인하고 직접 보내게 하는 것을 기본으로 한다. 사용자가 "바로 보내"라고 분명히 말한 경우에만 보낸다.

## 방법 2 · 하네스로 보내기

패키지 루트의 `harness/mailer.py`가 사용자의 Gmail 계정으로 보낸다. 먼저 설정을 확인한다.

```sh
python3 harness/mailer.py doctor
```

설정이 안 돼 있으면 사용자가 직접 하도록 안내한다. 값을 대화창에 붙여 넣게 하지 않는다.

1. Google 계정에서 2단계 인증을 켠다.
2. https://myaccount.google.com/apppasswords 에서 앱 비밀번호를 만든다. 계정 비밀번호가 아니다.
3. 자기 터미널에서 환경 변수로 지정한다.

```sh
export GMAIL_ADDRESS=<YOUR_ADDRESS>
export GMAIL_APP_PASSWORD=<YOUR_APP_PASSWORD>
```

보낼 때는 두 단계로 한다. 먼저 미리보기를 실행해 받는 사람, 제목, 첨부 크기를 사용자에게 보여 준다.

```sh
python3 harness/mailer.py send report.html report.pdf --subject "[기업 분석] NVDA · 2026-11-20" --summary "결론 두세 줄"
```

`--to`를 생략하면 본인에게 보낸다. 다른 사람에게 보내려면 `--to`를 받는 사람마다 붙인다. 미리보기의 `outsideRecipients`에 주소가 있으면 외부로 나가는 메일이라고 알린다. 사용자가 확인하면 같은 명령에 `--confirm`을 붙여 보낸다.

```sh
python3 harness/mailer.py send report.html report.pdf --subject "[기업 분석] NVDA · 2026-11-20" --summary "결론 두세 줄" --confirm
```

## 지킬 것

- 확인받은 받는 사람, 제목, 첨부와 다르게 보내지 않는다. 하나라도 바뀌면 다시 확인받는다.
- 첨부는 HTML과 PDF만, 합계 20MB까지, 받는 사람은 5명까지다.
- 본문 끝에 조사 자료이며 투자 조언이나 권유가 아니라는 문장이 자동으로 붙는다. 지우지 않는다.
- 여러 사람에게 정기적으로 보내는 대량 발송은 하지 않는다.
- 오류가 나면 오류 문장만 전하고 앱 비밀번호를 다시 보여 달라고 하지 않는다.
