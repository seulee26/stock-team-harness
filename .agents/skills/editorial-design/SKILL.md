# 편집 디자인

## 원고

- 가장 먼저 알아야 할 판단을 한 줄로 적고 이유를 짧은 문단으로 붙인다. 문단 하나에는 한 가지 이야기만 담는다. 문단이 길다면 문장을 줄이고, 이야기가 바뀌는 곳에서 문단을 나눈다.
- 제목만 내려 읽어도 흐름을 따라갈 수 있게 쓴다. 조건과 행동은 같은 묶음에 두고, 예시는 짧은 문단으로 이어 쓴다. 조건, 시점, 수치와 출처를 확인할 수 있게 남긴다.
- 문단은 실제 문단으로 만든다. 화면 폭에 맞춰 줄 끝을 강제로 자르지 않는다. '97.17달러', '47%', '11월 19일'처럼 의미가 이어지는 표현은 가능한 한 한 줄에 둔다.

## 화면과 종이

- 모바일은 한 열을 기본으로 삼는다. 한국어 본문은 17px 안팎, 행간은 글자 크기의 1.6~1.8배에서 시작하고 320px 화면에서 읽어 본다. 꼭 필요한 수치만 크거나 굵게 표시한다. 보조 설명과 출처도 읽히는 크기와 색 대비를 유지한다.
- PDF는 A4 본문 11.5~12pt를 출발점으로 삼는다. 페이지를 채우려고 글자 크기나 행간을 줄이지 않는다. 제목과 첫 문장, 표 머리글과 행, 가격 조건과 설명이 서로 떨어지지 않게 배치한다.
- 표는 짧은 값을 나란히 비교할 때 쓴다. 좁은 화면에서 열이 지나치게 좁아지면 같은 정보를 짧은 세로 목록으로 편집한다. 출처는 관련 본문 가까이에서 찾을 수 있게 연결한다.

## 전달 전 확인

320px와 일반 휴대폰 폭에서 첫 화면, 표, 숫자 줄바꿈을 확인한다. PDF는 전 페이지를 렌더링해 글자, 잘린 행, 홀로 남은 제목, 여백과 쪽 번호를 확인한다. 추출 텍스트와 링크를 대조해 중요한 금액·조건·출처가 두 형식에 모두 들어 있는지 확인한다. 문제를 발견하면 원고와 템플릿을 수정해 다시 렌더링한다.
