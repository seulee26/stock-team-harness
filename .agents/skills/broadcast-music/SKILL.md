# 방송 배경 음악

인터넷의 음악은 대부분 마음대로 쓸 수 없다. 이 스킬은 Openverse(공개 라이선스 음원 목록)에서 다시 써도 되는 곡만 찾고, 받은 파일 옆에 라이선스 기록을 남긴다. 영상은 `report-broadcast` 스킬로 만든 대본이 있어야 한다.

## 시작 전에 확인

이미 밝힌 항목은 묻지 않는다. "알아서 해 줘"에는 기본값을 쓴다.

| 항목 | 기본값 |
| --- | --- |
| 분위기 | 뉴스 속보처럼 긴박한 느낌 (검색어 `breaking news`) |
| 길이 | 60초 이상. 영상보다 짧으면 자동으로 반복된다 |
| 음악 크기 | 0.14 (해설이 또렷하게 들리는 정도) |

## 순서

1. 찾는다. 검색어는 영어가 결과가 많다. 예: `breaking news`, `news theme`, `corporate`, `tension`.

```sh
python3 harness/music.py search "breaking news" --min-seconds 60
```

결과마다 제목, 만든 사람, 라이선스, 길이, 원본 페이지(`source`)가 나온다. 비영리(NC), 변경 금지(ND), 동일조건(SA) 곡은 결과에서 빠진다.

2. 후보 두세 곡을 사용자에게 보여 주고 고르게 한다. 표에 제목, 만든 사람, 라이선스, 길이, 표기가 필요한지를 적는다. "알아서 해 줘"라고 했으면 60초 이상인 곡 중 첫 번째를 고르고 무엇을 골랐는지 알린다. 받기 전에 `source` 주소를 열어 라이선스 표기가 검색 결과와 같은지 확인한다. 다르면 받지 않는다.

3. 받는다. 파일 옆에 `.license.json`이 함께 생긴다.

```sh
python3 harness/music.py fetch <id> --out broadcast/music/곡이름.wav
```

4. 영상에 깐다. 해설이 나올 때는 음악이 자동으로 작아지고, 처음과 끝은 서서히 커지고 작아진다.

```sh
python3 harness/broadcast.py build 대본.script.json 출력.mp4 --music broadcast/music/곡이름.wav --music-volume 0.14
```

CC BY 곡이면 마지막 장면 아래에 "음악: 제목 · 만든 사람 · 라이선스"가 자동으로 들어가고, `.manifest.json`의 `music`에도 남는다.

5. 영상을 웹이나 영상 서비스에 올릴 때는 설명란에도 같은 표기를 적으라고 사용자에게 알린다.

```sh
python3 harness/music.py credit broadcast/music/곡이름.wav
```

## 사용자가 가진 음악을 쓸 때

사용자가 직접 만들었거나 사용권을 산 곡이면 표기 문구를 사용자가 정한다. 권리를 확인했는지 한 번 묻고, 확인했다고 하면 아래처럼 넣는다. 확인하지 못한 곡은 넣지 않는다.

```sh
python3 harness/broadcast.py build 대본.script.json 출력.mp4 --music 내곡.mp3 --music-credit "곡명 · 만든 사람 · 사용권 구매"
```

## 지킬 것

- 유튜브나 음원 서비스에서 음악을 내려받아 쓰지 않는다. 방송사 시그널 음악, 가요, 영화 음악도 쓰지 않는다.
- 라이선스 기록(`.license.json`)이 없고 사용자가 권리를 확인해 주지 않은 음악은 프로그램이 거절한다. 그대로 알린다.
- 라이선스는 목록에 적힌 값이다. 올린 사람이 권리자가 아닐 수도 있으니 원본 페이지를 한 번 확인하고, 상업적으로 크게 쓰는 영상이면 사용자가 직접 확인하라고 알린다.
- 음악이 해설을 덮으면 안 된다. 음악 크기는 0.1~0.2에서 고르고, 직접 들어 보지 못했으면 그렇게 밝힌다.
- 받은 음악 파일을 따로 묶어 다시 배포하지 않는다. 영상에 넣어 쓰는 데만 쓴다.
