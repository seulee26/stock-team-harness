# 실적 발표 검토

1. 회계연도·분기, 발표시각과 정규장·시간외 구분을 확인한다. `python3 harness/integrations.py filings TICKER --limit 3`으로 최근 SEC 공시 원문을 찾는다. 회사의 실적 발표, 8-K·10-Q·10-K와 발표 자료에서 매출, 이익, 현금흐름과 해당 종목의 핵심 사업 지표를 확보한다.
2. 지난 분기 회사 가이던스, 발표 전 컨센서스, 실제값, 새 가이던스를 같은 회계기간·통화·기준으로 맞춘다. GAAP과 조정 EPS, 보고 환율과 고정 환율, 실제 실적과 전망을 명확히 표기한다. 비교 가능한 컨센서스가 없으면 공개 가이던스 구간과만 대조한다.
3. 예상 차이는 실제값에서 비교 기준을 뺀다. 기준값이 0이거나 부호가 바뀌면 절대 차이와 방향을 적는다. 회사 가이던스는 범위와 중간값을 함께 남긴다. 사업부나 일회성 항목이 변화를 설명하면 회사 원문을 연결한다.
4. 발표 직전 완료된 정규장 종가와 발표 후 처음 확인 가능한 세션의 가격·시각을 적는다. 동시간대 섹터나 시장 변동을 필요에 따라 함께 표시한다. 발표 전이면 실적 확인 포인트와 발표 일정을 제시한다.
5. 기존 투자 판단이 달라졌는지, 다음 분기에 검증할 수치와 다음 발표 시점을 가장 먼저 요약한다.

Anthropic Financial Services의 `earnings-reviewer` 절차는 `python3 harness/integrations.py financial-skills earnings`에 표시된 로컬 스킬을 읽어 적용한다. 공개 문서로 검증할 수 있는 항목을 맡기고 사용한 실제 출처를 결과에 남긴다.
