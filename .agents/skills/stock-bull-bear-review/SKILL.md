# 상승·하락 논지 검토

1. 종목, 기준시각, 투자 기간과 현재 비교 가격을 확정한다. 상승 역할과 하락 역할에 똑같은 공개 근거와 출처를 제공한다. 공시·시세·뉴스·기술 자료는 필요한 항목만 포함한다.
2. 상승 역할은 수익원, 성장 가정과 촉매를 연결한다. 하락 역할은 가정이 깨질 사건, 현금흐름·밸류에이션에 미칠 크기와 현재 가격에 이미 반영된 기대를 검토한다. 양쪽 모두 관찰된 사실, 추정, 확인이 필요한 가정을 명시한다.
3. 위험 검토는 양쪽의 가장 강한 주장을 하나씩 골라 원문, 시각과 계산을 대조한다. 동시에 성립할 수 있는 주장과 같은 가정에서 갈리는 주장을 확인한다. 같은 근거를 인용한 여러 모델의 의견을 서로 독립된 증거로 세지 않는다.
4. 결과에는 현재 검토 의견, 가장 설득력 있는 양쪽 근거, 판단을 바꿀 가격·공시·실적 조건을 짧게 정리한다. 조건마다 시점, 관측 출처와 다음 확인 일정을 붙인다. 시장 가격이 없으면 확인할 공시·사업 지표를 제시한다.

Codex나 Claude 역할로 바로 진행할 수 있다. 사용자가 TradingAgents 자체 모델 실행을 요청하고 `STOCK_HARNESS_DEBATE_KEY`가 로컬에 설정되어 있으면 `python3 harness/integrations.py debate TICKER --date YYYY-MM-DD --model MODEL`을 사용한다. 날짜는 오늘의 미국 동부 날짜다. 이 경로는 별도 모델 API 비용이 발생할 수 있다. 모델의 주가·실적 주장은 공개 자료로 대조하고 실제 사용한 검토 방식과 독립 검토 여부를 결과에 표시한다. 실계좌 정보와 주문 도구는 토론 입력에서 제외한다.
