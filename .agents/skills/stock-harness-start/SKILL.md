# 시작 가이드

처음 쓰는 사람이 5분 안에 첫 리포트를 받도록 안내한다. 주식과 터미널을 모르는 사람을 기준으로 쉬운 말로 설명하고, 한 번에 한 단계만 안내한다.

## 1. 지금 상태 확인

- 현재 폴더에 `harness/`와 `service/`가 있는지 확인한다. 있으면 전체 기능을 쓸 수 있다. 없으면 플러그인만 설치된 상태이며 공개 자료 리서치는 그대로 쓸 수 있다.
- 토스증권 연결, 로컬 대시보드, 백테스트, 데이터 연결, 오픈소스 도구 연동은 하네스 폴더가 있어야 한다. 폴더가 없는데 이 기능을 원하면 https://github.com/seulee26/stock-team-harness 에서 받아 그 폴더에서 다시 시작하도록 안내한다.
- 확인 결과는 "지금 바로 쓸 수 있는 것"과 "추가 준비가 필요한 것"으로 나눠 두세 줄로 알린다.

## 3. 첫 리포트 만들기

- 사용자가 종목을 말하면 미국 종목은 `us-stock-research`, 국내 종목은 `kr-stock-research` 스킬로 바로 분석을 시작한다. 종목을 정하지 못하면 관심 있는 회사 이름을 묻고, 그래도 없으면 누구나 아는 대형주 하나를 예시로 제안한다.
- 분석이 몇 분 걸린다는 것과, 여러 전문 역할이 팀별로 나눠 조사한 뒤 한 장의 리포트로 정리한다는 것을 먼저 알린다.
- 리포트가 나오면 파일 위치를 알려 주고, 결론·조건·조심할 점을 세 줄로 요약한다.
- 리포트는 조사 자료이며 투자 조언이나 권유가 아니라는 점, 투자는 본인이 증권사에서 직접 한다는 점을 한 번 알린다.

## 4. 토스증권 연결 안내 (원할 때만)

- 연결하면 보유 종목, 수익률, 매수 가능 금액, 계좌에 적용된 수수료율 기준으로 답할 수 있다고 설명한다. 연결하지 않아도 공개 자료 리서치는 모두 된다.
- 준비물은 토스증권 Open API 키, Python 3.9 이상, Node.js 20 이상이다. Mac, Linux, Windows의 WSL에서 지원한다.
- 사용자가 자기 터미널에서 `python3 service/launch.py --personal`을 직접 실행하도록 안내한다. 키는 그 터미널의 숨김 입력에만 넣는다.
- 키, 토큰, 계좌번호를 대화창에 붙여 넣지 말라고 먼저 알린다. 사용자가 대화에 붙여 넣으면 사용하지 말고, 키를 다시 발급받도록 권한다.
- 조회 전용이며 주문 기능이 없다는 것, 계좌 정보는 공유 리포트에 넣지 않는다는 것을 알린다. 세부 절차는 `stock-toss-readonly` 스킬과 `harness/README.md`를 따른다.

## 5. 다음에 해 볼 것

첫 리포트를 받은 뒤 아래 중 상황에 맞는 것 하나만 권한다.

- 같은 종목을 실적 발표 뒤에 다시 물어 달라진 점 확인하기
- `stock-bull-bear-review`로 반대 의견 듣기
- `hedge-fund-desk`로 투자위원회를 열어 여러 팀의 의견 모으기
- `research-desk`로 받을 수 있는 리포트 종류 보기
- `thesis-tracker`로 내 생각을 기록해 두고 나중에 점검하기
- `stock-data-connections`로 DART·FRED·에이전트 스토어 연결하기
- `python3 harness/quant.py demo`로 백테스트가 어떻게 나오는지 보기
- `python3 service/launch.py`로 로컬 대시보드 열어 보기
- `stock-harness-integrations`로 오픈소스 도구 네 가지 설치 상태 확인하기
- `stock-harness-vibe-coding`으로 원하는 기능을 말로 설명해 추가하기

## 막혔을 때

- 명령을 찾을 수 없다는 오류가 나오면 어떤 프로그램이 없는지 이름으로 알려 주고 설치 주소를 안내한다.
- 스킬이 보이지 않으면 Claude Code는 `claude --plugin-dir ./claude/us-stock-team`으로, Codex는 하네스 폴더를 연 상태로 다시 시작하도록 안내한다.
- 토스 조회가 실패하면 오류 종류만 전하고, Open API에 등록한 IP와 키 입력을 확인하도록 안내한다.
