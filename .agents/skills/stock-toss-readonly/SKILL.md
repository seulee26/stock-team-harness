# 토스증권 로컬 조회

- 보유 수량·수익률·주문 가능 금액을 요청받으면 `python3 harness/stock_harness.py portfolio`를 실행한다. 여러 계좌가 반환되면 사용자가 지정한 계좌만 조회한다. 원화·달러, 계좌가 제공한 수익률 기준과 시각을 함께 표시한다.
- 매도 비용은 거래소·체결금액·통화가 맞는지 확인하고 `python3 harness/stock_harness.py sale-fee KOSPI 100000000` 형태로 계좌 적용 비용을 계산한다. 계좌 정보 없이 계산해야 하면 공개 요율을 쓰고 적용 범위를 알린다.
- 실행 명령과 로컬 환경 파일 설정은 패키지의 `harness/README.md`를 따른다. 증권사 응답으로 연결과 조회 성공을 확인한다. 인증이 실패하면 오류 종류만 전달하고 비밀 값은 하네스 로컬 환경에서 입력하도록 안내한다.
- 계좌 원본·보유 목록·거래내역·인증 값은 외부 플러그인, 별도 외부 모델 호출, 공유 리포트, 릴리스에서 제외한다. 공개 조사로 넘길 시세는 `market-packet`으로 추출한다. 호출 결과는 요청한 사용자에게 필요한 범위만 전달한다.
