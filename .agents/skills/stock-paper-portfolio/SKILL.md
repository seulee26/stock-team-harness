# 모의 포트폴리오

1. `python3 harness/integrations.py paper-demo`로 예제 실행 및 출력 항목을 확인한다. 가상 포트폴리오의 시작 현금·통화, 거래 시나리오와 입력 가격을 명시한다. 재현할 사례는 `harness/README.md`의 시나리오 형식에 맞춰 `python3 harness/integrations.py paper PATH_TO_SCENARIO`로 실행한다.
2. 투자 신호가 생긴 날짜와 체결 가격의 날짜를 분리한다. 과거 검증은 각 시점에 공개된 자료만 사용한다. 기본 비용 모델은 `zero`로 수수료와 슬리피지 없이 계산한다. 사용한 체결 가격 가정과 비용 범위를 결과에 적는다.
3. 가상 체결·최종 현금·보유 수량을 응답에서 확인한다. 지출 가능 현금이나 보유 수량을 초과해 입력이 거절되면 해당 거래를 찾는다. 종료 평가액과 수익률이 필요하면 합의된 종료 가격을 사용해 현금과 잔여 포지션을 합산한다. 기준 지수나 동일 보유전략을 함께 계산할 땐 같은 통화와 시점을 사용한다.
4. 공유할 산출물에는 가상 자금, 가격·체결 가정, 기간과 재현 명령을 포함한다. `paper-demo`를 실행한 경우 예제 결과로 표시한다. 모의 장부에는 실제 계좌번호, 보유내역과 주문 내역을 넣지 않는다.
