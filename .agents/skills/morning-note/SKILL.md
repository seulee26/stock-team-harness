# 모닝 브리프

한 장 안에 끝낸다. 바쁜 아침에 2분 안에 읽을 수 있어야 한다.

## 시작 전에 형식 확인

조사를 시작하기 전에 사용자에게 아래를 한 번에 묻는다. 선택지를 고르게 하는 질문 도구가 있으면 그것을 쓰고, 없으면 번호를 붙여 짧게 묻는다. 답을 받은 뒤에 조사를 시작한다.

1. 대상 시장: 한국장, 미국장, 둘 다
2. 깊이: 한 장 요약, 표준, 심층 (기본값: 한 장 요약)
3. 받는 형식: 채팅 답변, HTML 파일, HTML과 PDF (기본값: 채팅 답변)
4. 읽는 사람: 주식이 처음인 사람, 경험이 있는 사람 (기본값: 처음인 사람)

- 사용자가 요청에서 이미 밝힌 항목은 다시 묻지 않는다. 네 가지가 모두 정해져 있으면 묻지 않고 진행한다.
- 질문은 한 번만 한다. 사용자가 "알아서 해 줘"라고 하거나 답하지 않은 항목은 기본값을 쓰고, 어떤 기본값을 썼는지 결과 첫머리에 한 줄로 적는다.
- 고른 깊이에 맞춰 조사 범위와 부르는 역할 수를 줄이거나 늘린다. 한 장 요약에 심층 조사를 붙이지 않는다.

## 순서

1. 오늘 날짜와 대상 시장(한국장 또는 미국장)을 정한다. 한국장 브리프는 전날 미국 마감이, 미국장 브리프는 당일 아시아·유럽 흐름과 선물이 밤사이 재료다.
2. 아래 조사를 병렬로 맡긴다.
   - `strategist`: 주요 지수, 업종 등락, 금리·달러·유가·변동성의 밤사이 변화
   - `news`: 최근 24시간의 핵심 뉴스 3~5건과 영향
   - `macro`: 오늘 나오는 지표와 중앙은행 일정
3. `python3 harness/desk.py event-list --days 2`로 기록해 둔 일정을 확인한다.
4. 오늘 볼 것 세 가지를 고른다. 각각 왜 중요한지와 어느 쪽으로 해석될지를 한 줄로 쓴다.

## 형식

1. 기준 시각과 오늘의 한 줄
2. 밤사이 시장: 지수·금리·환율·원자재 표 (값, 등락, 기준 시각)
3. 핵심 뉴스 3~5건: 사실 한 줄, 영향 한 줄
4. 오늘 일정: 시각, 내용, 영향 크기
5. 오늘 볼 것 세 가지와 각각의 위험

지수 선물이나 장전 거래 가격은 정규장 종가와 구분해 적는다. 확인하지 못한 값은 비워 두고 채우지 않는다.

## 발행 전 점검

1. `editor` 역할에 초안을 보내 쉬운 말, 구조, 숫자와 출처의 일치를 점검받는다.
2. `compliance` 역할에 표현, 고지, 개인정보, 출처를 점검받는다.
3. 파일이 필요하면 `us-stock-research` 스킬의 렌더링 절차와 `editorial-design` 스킬로 한국어 HTML을 만든다.

전문 역할을 쓸 수 없는 환경에서는 현재 세션이 같은 항목을 직접 확인하고 독립 검토를 거치지 않았다고 밝힌다. 리포트는 조사 자료이며 투자 조언이나 권유가 아니라고 적는다. Codex에서는 역할 이름이 `news_desk`, `market_sentiment`, `technical_analyst`, `sector_analyst`, `market_strategist`, `idea_screener`, `report_editor`, `compliance_officer`, `performance_analyst`다.
