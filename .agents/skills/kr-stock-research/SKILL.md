# 국내주식 리서치

종목명이나 6자리 종목코드를 상장 시장(KOSPI·KOSDAQ), 보통주·우선주, 통화(KRW)까지 확인한다. 기준 시각은 한국 시간(KST)으로 적고, 기본 가격은 KRX 정규장(09:00~15:30) 종가를 쓴다. 사용자가 기준일만 주면 그날까지 공시된 자료와 마지막 완료 거래일 종가를 쓴다.

## 시작 전에 형식 확인

리포트를 만들 때만 적용한다. 한두 문장으로 답할 수 있는 사실 질문이나 단순 계산은 묻지 않고 바로 답한다.

조사를 시작하기 전에 아래 네 가지를 한 번에 묻는다. 선택지를 고르게 하는 질문 도구가 있으면 그것을 쓰고, 없으면 번호를 붙여 짧게 묻는다. 답을 받은 뒤에 조사를 시작한다.

1. 관점: 새로 살지 검토, 보유 종목 점검, 실적 확인, 다른 종목과 비교 (기본값: 새로 살지 검토. 종목은 기본값이 없다)
2. 깊이: 한 장 요약, 표준, 심층 (기본값: 표준)
3. 받는 형식: 채팅 답변, HTML 파일, HTML과 PDF (기본값: HTML 파일)
4. 읽는 사람: 주식이 처음인 사람, 경험이 있는 사람 (기본값: 처음인 사람)

- 사용자가 요청에서 이미 밝혔거나 `research-desk`·`stock-harness-start`에서 이미 정한 항목은 다시 묻지 않는다. 네 가지가 모두 정해져 있으면 묻지 않고 진행한다.
- 질문은 한 번만 한다. 사용자가 "알아서 해 줘"라고 하거나 답하지 않은 항목은 기본값을 쓴다. 기본값이 없는 항목은 사용자가 "알아서 해 줘"라고 해도 반드시 묻는다.
- 기본값을 썼으면 조사를 시작한다고 알리는 첫 답에 어떤 기본값을 썼는지 한 줄로 적고, 결과 첫머리에도 남긴다.
- 깊이에 따라 범위를 정한다. 한 장 요약은 `kr-fundamentals`와 `kr-market`만 부르고 조건은 리드가 직접 쓴다. 표준은 `kr-flows`, `valuation`, `trade-timing`을 더한다. 심층은 `risk-review`와 필요하면 `macro`까지 부른다. 아래 순서에 적힌 역할은 표준 깊이 기준이며, 깊이가 다르면 이 줄이 우선한다.
- 채팅 답변을 고르면 파일을 만들지 않는다. 파일은 사용자가 정한 폴더에, 정하지 않았으면 작업 폴더의 `reports/`에 `YYYY-MM-DD-리포트종류-대상.html`로 저장하고 경로를 알려 준다. 예: `2026-11-20-company-NVDA.html`, `2026-11-20-sector-반도체.html`.
- 파일을 만들었으면 끝에 Gmail로도 받을지 한 번 묻고, 원하면 `report-email` 스킬로 넘긴다.
- 리서치 위키가 만들어져 있으면(`python3 harness/wiki.py status`가 성공하면) 파일을 위키에 넣을지도 함께 묻고, 원하면 `research-wiki` 스킬로 넘긴다. 방식이 drive-connector인데 Drive 커넥터 도구가 보이지 않으면 묻지 않는다.
- 역할 이름은 Claude Code에서 `us-stock-team:` 접두사가 붙어 보일 수 있다. 같은 역할이다.

## 먼저 확인

오늘 날짜를 적고 가장 최근 정기보고서와 잠정실적 공시일을 찾는다. 석 달이 넘은 실적만 있으면 그 사실을 맨 앞에 적는다.

## 팀 운영

1. `kr-fundamentals`에 DART 공시·재무·지배구조를, `kr-market`에 시세·지수 대비 수익률·일정을 병렬로 맡긴다. 종목코드, 기준 시각, 범위를 함께 전달한다.
2. 투자의견이나 수급을 다루면 `kr-flows`를 함께 부른다.
3. 가치평가가 필요하면 미국 데스크와 같은 `valuation` 역할에 원화 기준 가격과 재무를 주고, 비교 대상은 국내 동종업체로 잡게 한다. 매수·매도 조건은 `trade-timing`, 반증 검토는 `risk-review`에 맡긴다.
4. 금리·환율이 실적에 크게 걸리는 업종(수출주, 금융, 건설)은 `macro`에 배경을 묻는다.

Codex에서는 `kr_stock_fundamentals`, `kr_stock_market`, `kr_stock_flows`, `us_stock_valuation`, `us_stock_trade_timing`, `us_stock_risk_review`, `macro_rates`를 쓴다.

## 데이터 연결

자료는 아래 순서로 고른다. 연결이 없으면 다음 단계로 넘어가고 어떤 자료를 썼는지 리포트에 적는다.

| 순서 | 자료 | 쓰는 법 |
| --- | --- | --- |
| 1 | 에이전트 스토어 MCP (`dart`, `corporate-data`, `corp-financials`, `kr-equity-report`, `capital-markets`, `bok-stats`) | 도구가 보이면 그대로 호출 |
| 2 | OpenDART 본인 키 | `python3 harness/connectors.py dart-filings 005930`, `dart-financials 005930 --year 2025` |
| 3 | 토스증권 공개 시세 | `python3 harness/stock_harness.py market-packet 005930` |
| 4 | 일봉 (FinanceDataReader 설치 시) | `python3 harness/connectors.py bars 005930 --source fdr --start 2025-01-01 --end 2026-11-20 --out 005930.csv` |
| 5 | 공개 웹 | dart.fss.or.kr, kind.krx.co.kr, 회사 IR 자료 |

연결 방법은 `stock-data-connections` 스킬에 있다. 키는 사용자가 자기 터미널 환경 변수에만 넣는다.

## 국내 시장에서 따로 볼 것

- 연결과 별도, 누적과 3개월 실적을 구분한다.
- 최대주주 지분, 지주회사와 자회사 중복상장, 자사주 소각 여부, 배당 정책.
- 유상증자, 전환사채, 물적분할처럼 주식 수가 늘어나는 사건.
- 외국인·기관 수급, 공매도 잔고, 신용잔고.
- 우선주와 보통주의 가격 차이.
- 매도할 때 드는 증권거래세와 수수료는 `stock-sale-fee` 역할에 맡긴다. 양도소득세나 배당 세금을 물으면 `stock-tax-kr` 스킬로 넘긴다.

## 결과 작성

- 맨 앞에 기준일, 시세 시각, 핵심 판단을 적는다. 금액은 원 단위에 조·억을 붙여 읽기 쉽게 쓴다.
- 지금 판단과 이유, 판단을 바꿀 조건을 먼저 보여 준다. 조건은 원화 절대 가격과 확인할 공시로 적는다.
- 주요 숫자 옆에 DART 원문 링크를 붙인다. 확인하지 못한 값은 [출처 없음]으로 표시하고 추정으로 메우지 않는다.
- 파일 형식을 골랐으면 `us-stock-research` 스킬의 렌더링 절차와 `editorial-design` 스킬을 따라 한국어 HTML로 만든다. 종목 표기는 `회사명 (종목코드)`로, 금액은 원화로 바꿔 쓴다. 채팅 답변을 골랐으면 같은 순서로 채팅에 쓴다.
- 내보내기 전에 `editor` 역할에 쉬운 말과 숫자 대조를, `compliance` 역할에 표현과 고지를 점검받는다. 한 장 요약은 리드가 같은 항목을 직접 확인한다.
- 수익을 보장하거나 사라·팔라고 지시하는 표현을 쓰지 않는다. 리포트는 조사 자료이며 투자 조언이나 권유가 아니라고 적는다. 주문은 사용자가 증권사에서 직접 한다.
