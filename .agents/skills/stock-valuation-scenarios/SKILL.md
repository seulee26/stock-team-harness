# 밸류에이션 시나리오

1. 검증된 주가와 기준시각, 희석주식수, 현금·부채, 재무기간과 각 출처를 정리한다. 회계에 포함된 리스·우선주·비지배지분과 순부채 조정의 일관성을 검토한다.
2. 사업 구조와 자본구조에 맞는 지표를 고른다. PER에는 같은 기간의 주당순이익을, EV 멀티플에는 매출이나 EBITDA 등 기업가치와 맞는 지표를 사용한다. 추정치와 과거 실적을 한 비교표에서 사용하면 해당 열에 기준을 적는다. 비교 기업을 선정한 이유를 표시한다.
3. 하락·기준·상승 시나리오별 매출 성장률, 마진, 멀티플 또는 할인율을 계산에 연결한다. 기업 현금흐름을 할인했다면 기업가치에 필요한 순부채 등을 조정한 뒤 희석주식수로 나눈다. 영구성장률은 할인율보다 작아야 한다. 주요 가정 한두 개를 움직여 범위를 비교한다.
4. 각 시나리오의 주당 가치와 현재가 기준 상승·하락률을 가정·기간과 함께 표기한다. 비상장 데이터나 향후 상장 주식수가 확인되지 않으면 검증 가능한 기업가치와 필요한 공개 항목부터 다룬다. 확률·기대수익을 쓸 때 산식과 확률의 근거를 남긴다.

Anthropic Financial Services에서 DCF와 비교기업 모델을 작성할 때는 `python3 harness/integrations.py financial-skills model`의 로컬 스킬을 읽는다. 투자 메모와 투자 수익률을 점검할 때는 `python3 harness/integrations.py financial-skills valuation`을 사용한다. 최종 값은 검산한 수치와 원문을 사용한다.
