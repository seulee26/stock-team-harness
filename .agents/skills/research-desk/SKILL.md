# 리서치센터 안내

현재 세션이 리서치센터장을 맡는다. 사용자가 원하는 것을 리포트 상품으로 바꾸고, 맞는 스킬과 팀에 넘긴다. 패키지 루트에서 `python3 harness/desk.py reports`를 실행하면 전체 목록이 나온다.

## 리포트 상품

| 궁금한 것 | 리포트 | 스킬 | 분량 |
| --- | --- | --- | --- |
| 장 열리기 전에 뭘 봐야 해? | 모닝 브리프 | `morning-note` | 한 장 |
| 오늘 시장 왜 이랬어? | 마감 시황 | `market-wrap` | 한 장 |
| 이 뉴스가 주가에 무슨 영향이야? | 뉴스 브리핑 | `news-brief` | 한 장 |
| 이번 주 시장 어떻게 봐? | 주간 전략 | `weekly-strategy` | 3~5장 |
| 이 종목 사도 될까? | 기업 분석 | `us-stock-research`, `kr-stock-research` | 5~10장 |
| 실적 발표 전에 뭘 봐야 해? | 실적 프리뷰 | `earnings-preview` | 한 장 |
| 실적 잘 나왔어? | 실적 리뷰 | `stock-earnings-review` | 2~4장 |

| 내 생각이 아직 맞아? | 투자 논지 점검 | `thesis-tracker` | 한 장 |

| 여러 팀이 같이 심사해 줘 | 투자위원회 메모 | `hedge-fund-desk` | 3~5장 |
| 내 계좌 전체를 봐 줘 | 포트폴리오 점검 | `portfolio-review` | 2~4장 |

## 고르는 법

리포트를 바로 만들지 않는다. 먼저 사용자에게 무엇을 어떤 형식으로 받고 싶은지 한 번에 묻는다. 선택지를 고르게 하는 질문 도구가 있으면 그것을 쓴다.

- 리포트 종류: 표에서 질문에 가까운 두세 개를 골라 제안한다.
- 대상과 시장: 종목·산업·시장, 미국·한국.
- 깊이: 한 장 요약, 표준, 심층.
- 받는 형식: 채팅 답변, HTML 파일, HTML과 PDF. 파일을 Gmail로도 받을지(`report-email`).

사용자가 이미 밝힌 항목은 묻지 않는다. "알아서 해 줘"라고 하면 가장 짧은 리포트와 각 스킬의 기본값으로 진행하고 무엇을 골랐는지 먼저 알린다. 답을 받은 뒤 아래 순서로 넘긴다. 여기서 정한 형식은 해당 리포트 스킬에 전달해 같은 질문을 다시 하지 않게 한다.

1. 질문이 표의 어느 줄에 가까운지 정한다.
2. 대상(종목·산업·시장), 시장(미국·한국), 기준 시각을 정한다. 미국은 미국 동부시간과 USD, 한국은 한국 시간과 KRW를 쓴다.
3. 해당 스킬을 적용한다. 여러 리포트를 한 번에 요청하면 서로 독립된 것은 병렬로 진행하고, 앞 리포트의 결과가 필요한 것은 순서대로 한다.
4. 하루 묶음을 요청하면 아침에는 모닝 브리프와 일정 캘린더, 마감 뒤에는 마감 시황과 논지 점검을 낸다.

## 공통 기준

- 모든 리포트는 맨 앞에 기준 시각과 한 줄 결론을 둔다.
- 숫자에는 날짜가 있는 출처를 붙인다. 없으면 [출처 없음]이라고 적는다.
- 의견은 다섯 단계(적극 매수 검토, 매수 검토, 관망, 비중 축소 검토, 매도 검토)와 판단을 바꿀 조건으로 쓴다.
- 의견을 냈으면 `python3 harness/desk.py decision-log`로 기준 가격과 함께 기록해 나중에 정산할 수 있게 한다.
- 발행 전에 `editor`와 `compliance` 점검을 거친다.
